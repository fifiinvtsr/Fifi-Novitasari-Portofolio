# Fifi-Novitasari-Portofolio

Personal Portfolio Website of **Fifi Novitasari** — Business Information Systems Student at State Polytechnic of Malang (Polinema).

## ✨ Features
- **Modern Dark Aesthetic**: Clean, responsive layout with smooth scroll and reveal animations.
- **About & Skills**: Soft Skills and curated HD Hard Skills showcase (Canva, Office, Google Antigravity, Python, Google Colab, Looker, Figma, InDesign, Excel, Word).
- **Work & Internship Experience**: Detailed showcase of roles, responsibilities, and visual galleries.
- **Freelance Graphic Designer**: Showcase of poster research, event flyers, and social media feed design.
- **My Certification**: Interactive lightbox gallery of academic honors, competitions, and professional AI/tech certifications.
- **Achievement & Projects**: Comprehensive list of national and campus achievements, case studies, DevFest roles, and research projects.
- **Interactive Lightbox**: Full-resolution pop-up modal for all certificates and project showcases.

## 🛠️ Built With
- **HTML5**: Semantic markup
- **CSS3**: Vanilla CSS with custom properties, glassmorphism, responsive grid & flexbox
- **JavaScript**: Smooth scroll, scroll reveal observers, dynamic modals, and interactive lightboxes
